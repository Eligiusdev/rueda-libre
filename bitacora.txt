3. ROLES DE LAS TECNOLOGÍAS WEB EN RUEDA LIBRE

* HTML HyperText Markup Language:
  - Rol: Define la estructura lógica, el esqueleto y el contenido semántico del sitio web.
  - Ejemplo concreto: El uso de las etiquetas <h1> para el nombre del negocio y <ul> junto 
    a <li> para desplegar el listado de los servicios disponibles de bicicletas.

* CSS Cascading Style Sheets:
  - Rol: Controla la presentación visual, el diseño estético, los colores, las fuentes y la 
    adaptabilidad a dispositivos (Layout).
  - Ejemplo concreto: Definir un color de fondo verde ecológico (#4CAF50) para el menú, cambiar 
    el tamaño de letra de los precios y ocultar elementos en pantallas móviles para que sea responsive.

* JavaScript:
  - Rol: Aporta interactividad dinámica, lógica de programación del lado del cliente y control 
    de comportamientos en tiempo real.
  - Ejemplo concreto: Programar un formulario de reserva interactivo que calcule automáticamente 
    el precio total del alquiler basándose en el número de horas seleccionadas por el usuario.
